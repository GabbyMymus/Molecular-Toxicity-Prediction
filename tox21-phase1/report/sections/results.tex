\section{Results and Discussion}
\label{sec:results}

We report final test performance across the 432 experimental evaluations (3 model architectures $\times$ 2 feature sets $\times$ 2 splitting regimes $\times$ 3 random seeds $\times$ 12 toxicity endpoints). Test metrics are computed strictly using the frozen configurations selected during scaffold validation tuning (commit \texttt{041892c}). All performance tables present the mean and sample standard deviation across random seeds 0, 1, and 2.

Several core findings emerge from this comparison:
\begin{enumerate}
    \item \textbf{Random Forest Superiority:} Multi-task Random Forest trained on hybrid features (\texttt{morgan+desc}) achieves the highest overall predictive performance across both evaluation metrics, recording an average ROC AUC of $0.7762 \pm 0.0020$ and PR AUC of $0.4035 \pm 0.0042$.
    \item \textbf{Gradient Boosting Competitiveness:} XGBoost trained on hybrid features achieves near-identical PR AUC ($0.4010 \pm 0.0045$) and strong ROC AUC ($0.7606 \pm 0.0036$), demonstrating that tree ensembles are uniformly well-suited for tabular multi-task toxicity prediction.
    \item \textbf{Linear Baseline Competitiveness:} L2-regularized Logistic Regression achieves an average ROC AUC of $0.7317$ on hybrid features, providing a competitive, low-variance linear benchmark. Because liblinear's coordinate descent is deterministic under fixed convergence tolerances, its standard deviation over seeds is exactly $0.0000$.
\end{enumerate}

\begin{figure}[t]

\includegraphics[width=0.98\columnwidth]{descriptor_benefit.png}

The empirical evidence strongly confirms the utility of hybrid representations, while revealing a stark divergence between linear and non-linear estimators:
\begin{itemize}
    \item \textbf{Dramatic Boost in Tree Ensembles:} XGBoost derives massive gains from descriptor inclusion, increasing ROC AUC by $+0.0586 \pm 0.0059$ and PR AUC by $+0.0829 \pm 0.0025$. Similarly, Random Forest improves by $+0.0474$ ROC AUC and $+0.0333$ PR AUC. 
    \item \textbf{Mechanistic Rationale:} Tree-based algorithms naturally construct orthogonal decision boundaries over continuous physical dimensions (e.g., partitioning compounds into lipophilic vs.\ hydrophilic regimes via $\log P$) and can conditionally query whether specific Morgan substructures are present within those regimes. In contrast, linear models assign static weights to individual features without interaction terms; consequently, Logistic Regression experiences only a modest $+0.0162$ gain in ROC AUC and virtually zero gain in PR AUC ($+0.0006$).
\end{itemize}

\subsection{Chemical Novelty of the Test Sets}
\label{subsec:novelty}
To quantify the domain shift induced by scaffold partitioning, we computed for each test molecule the maximum Tanimoto coefficient to any training molecule, using the 2,048-bit Morgan fingerprints:
\begin{equation}
    T(u, v) = \frac{|u \cap v|}{|u \cup v|} = \frac{\sum_i u_i v_i}{\sum_i u_i + \sum_i v_i - \sum_i u_i v_i}
\end{equation}
Figure~\ref{fig:tanimoto} shows the distributions. The mean maximum similarity to the training set is $0.584$ (median $0.575$) for the random-split test molecules and $0.428$ (median $0.396$) for the scaffold-split test molecules. A training analog with $T \ge 0.85$ exists for $9.3\%$ of the random-split test molecules (72 of 771) but for only $1.7\%$ of the scaffold-split test molecules (13 of 771). The scaffold test set is therefore markedly less similar to the training data, although it is not free of close analogs. Both test sets contain different molecules, and the scaffold test set contains no acyclic molecules (all 1,753 are in the training set).

\end{figure}

\begin{figure}[t]

\label{fig:scaffold_vs_random}

The data reveals a severe and statistically significant ``scaffold penalty'' across all architectures:
\begin{itemize}
    \item On random splits, all models appear to perform exceptionally well, achieving mean ROC AUCs exceeding $0.84$--$0.86$ and PR AUCs exceeding $0.48$--$0.56$.
    \item When subjected to scaffold splitting, performance declines precipitously: ROC AUC drops by $8.5$ to $10.9$ percentage points, while PR AUC drops by $14.2$ to $17.0$ percentage points.
    \item Random Forest exhibits the highest structural resilience (lowest generalization drop of $-0.0845$ in ROC and $-0.1421$ in PR).
    \item This empirical drop directly mirrors the chemical novelty analysis reported in Section~\ref{subsec:novelty}: when models cannot exploit memorized structural analogs sharing identical scaffold cores, their predictive power relies solely on generalizable physicochemical and topological motifs.
\end{itemize}

\subsubsection{High-Predictability Endpoints}
The bioassays exhibiting the strongest predictability are SR-MMP, NR-AhR, and NR-AR-LBD:
\begin{itemize}
    \item \textbf{SR-MMP (Mitochondrial Membrane Disruption):} Achieves top performance across the entire benchmark (XGBoost ROC AUC $0.8790 \pm 0.004$, PR AUC $0.6400 \pm 0.004$). Mechanistically, uncoupling of the mitochondrial proton gradient is primarily governed by lipophilicity, delocalized positive charge, and membrane-permeable amphipathic structures. These properties are directly captured by calculated $\log P$, polar surface area, and aromatic ring counts.
    \item \textbf{NR-AhR (Aryl Hydrocarbon Receptor):} Random Forest achieves ROC AUC $0.8410 \pm 0.003$ and PR AUC $0.5960 \pm 0.002$. AhR binds planar, hydrophobic polycyclic aromatic hydrocarbons (PAHs) via a rigid, hydrophobic binding cavity, which map effectively to circular fingerprint motifs and molecular complexity metrics.
    \item \textbf{NR-AR-LBD:} XGBoost achieves ROC AUC $0.8570 \pm 0.002$, demonstrating that focused binding domain assays offer cleaner SAR signals than full-length nuclear receptor assays subject to co-factor modulation.
\end{itemize}

\subsubsection{Challenging Endpoints}
Conversely, endpoints such as NR-ER, SR-HSE, and SR-ATAD5 proved substantially more challenging:
\begin{itemize}
    \item \textbf{NR-ER (Estrogen Receptor):} Yields the lowest ROC AUC ($0.6850 \pm 0.004$ with RF), indicating complex conformational dynamics and promiscuous binding that 2D tabular features struggle to separate.
    \item \textbf{SR-HSE \& SR-ATAD5:} While exhibiting acceptable ROC AUCs ($\approx 0.74$--$0.78$), their PR AUCs remain low ($0.267$ and $0.247$, respectively). In both cases, active compounds represent less than $4\%$ of the library, and cellular heat-shock or DNA-repair cascades can be triggered by diverse, structurally heterogeneous toxicophores.
\end{itemize}
These difficult pathways underscore the intrinsic ceiling of 2D tabular representations and provide clear motivation for Phase 2, where deep graph architectures will learn multi-scale spatial and relational graph representations directly from molecular topology.
