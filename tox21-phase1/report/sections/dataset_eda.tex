\section{Dataset and Exploratory Analysis}
\label{sec:dataset}

We use the Tox21 twelve-assay screening dataset distributed by DeepChem. Each row
represents a chemical structure and each endpoint records an active (1), inactive
(0), or untested (missing) assay result. Missing values are retained as unknown
labels; they are excluded independently for each endpoint during model fitting and
evaluation. The source file contained 7,831 records. Parsing rejected 8 invalid
SMILES strings. We selected the largest connected fragment, canonicalized it with
RDKit, and grouped records by the resulting canonical SMILES. This produced 7,823
valid records before deduplication and 7,709 unique molecules afterward. Across
molecule-endpoint pairs, 44 conflicting label values were set to missing; agreeing
observations and single observed labels were retained. The full audit is recorded
in \texttt{data/processed/dedup\_log.txt}.

The largest-fragment step removes counterions and solvent fragments before
canonicalization, allowing alternate SMILES spellings of the same parent molecule
to merge. Duplicate labels are merged endpoint by endpoint: one observed label is
kept when all available observations agree, while disagreement becomes missing.
This avoids arbitrarily choosing a conflicting assay outcome and prevents duplicate
structures from crossing a data split. Figure~\ref{fig:eda-labels} summarizes the
assay coverage and class imbalance. Positive counts vary by endpoint, and label
coverage is incomplete, so accuracy and unmasked multi-label metrics would be
misleading. We therefore report endpoint-wise ROC AUC and average precision only
on rows with known labels.

Molecular size and topology vary substantially across the dataset, as shown by
molecular weight, heavy-atom count, and ring-count distributions in
Figure~\ref{fig:eda-properties}. These global properties complement the local
substructure information encoded by Morgan fingerprints. The distributions also
motivate fitting descriptor imputation and scaling on training rows only.

\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{../figures/eda_molecule_properties.png}
  \caption{Basic molecular property distributions after structure cleaning.}
  \label{fig:eda-properties}
\end{figure}

For the scaffold split, molecules are grouped by their Bemis--Murcko scaffold and
entire groups are assigned to one partition. The cleaned set has 7,709 molecules
and the saved split contains 6,167 training, 771 validation, and 771 test rows.
All 1,753 acyclic molecules have an empty scaffold and remain together in the
training partition. Figure~\ref{fig:eda-scaffolds} shows the long-tailed scaffold
size distribution and partition sizes. This split prevents a scaffold from
appearing in multiple partitions and provides a stricter estimate of performance
on chemical frameworks absent from training. A separate seeded random split uses
the same partition sizes as a complementary, less stringent reference.

The molecule-level missingness map is provided in Figure~\ref{fig:eda-missingness};
for legibility, it displays a regular sample of rows while retaining every assay.
Together, the audit, endpoint coverage, molecular-property distributions, and
scaffold statistics document the data used by all downstream feature and model
experiments. The figures are regenerated by \texttt{python scripts/06\_dataset\_eda.py}.
